# Lipidomics input

`lipidomics.xlsx` — LC-MS/MS lipidomics of isogenic WT and KRAS G12V cells under
four conditions (Control, 2-deoxyglucose, glucose starvation, UGCG inhibitor),
n = 3 replicates each (24 samples, 1,511 lipid features across 24 classes).

Layout: three header rows (column names, short sample names, cohort labels),
then one row per lipid species. The first 8 columns are metadata
(`feature, class, structuralcategory, functionalcategory, totallength, totaldb, totaloh, fullname`).

Source: experimental design matches Liu et al., *Nat Commun* 14, 465 (2023)
<https://doi.org/10.1038/s41467-023-36128-5>. Cite the original authors when reusing.
